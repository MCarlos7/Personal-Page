# Personal Page

My personal website developed with **React**. It showcases information about me, my projects, skills, and ways to get in touch. Ideal for portfolios and professional presentation.

[View live demo](https://mcarlos7.github.io/Personal-Page/)

---

## Technologies

- React 19 (Create React App)
- JavaScript, HTML, and CSS
- Bootstrap and React Bootstrap
- Framer Motion and React Icons

---

## Available Scripts

Install dependencies and start the development server:

```bash
npm install
npm start
```

Create a production build or deploy to GitHub Pages:

```bash
npm run build
npm run deploy
```

The CV link expects `public/CV_CarlosMariscal.pdf`.
